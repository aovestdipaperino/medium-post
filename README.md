# medium-post

A small static page, served with GitHub Pages, that hosts images referenced from a Medium post.

- `index.html` is a placeholder page.
- `images/` holds the image files, for example `images/mermaid-792270b8-e576-45de-8d21-0d50a74bfb0b.png`.

Images are linked as `https://aovestdipaperino.github.io/medium-post/images/<file>`.
